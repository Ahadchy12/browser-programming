# Lecture 02 – Semantic HTML & Structure

## 1. What I implemented in this lecture
- Built a semantic page header containing an `<h1>` heading and a short personal biography.
- Created a Portfolio section using semantic elements such as `<section>`, `<figure>`, and `<figcaption>`.
- Added a **“Skip to content”** link to improve accessibility for keyboard navigation.

---

## 2. Semantic choices I made (REQUIRED)

### Decision 1
- **Element(s) used:** `<header>` and `<footer>`
- **Location on the page:** At the top and bottom of the webpage.
- **Reason for using these elements:**  
  These elements act as structural landmarks that help browsers and screen readers identify the beginning and end of the page. The `<header>` contains introductory content, while the `<footer>` holds general site information.

---

## 3. Accessibility considerations
- Implemented a **Skip Link** so keyboard users can jump directly to the main content without navigating through the header every time.

---

## 4. What I learned
- I learned how to properly group media and captions using semantic elements like `<figure>` and `<figcaption>` instead of relying only on `<div>` elements.
