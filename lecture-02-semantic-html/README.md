
Lecture 02 – Semantic HTML & Structure
1. What I implemented in this lecture

Built a semantic page header containing an <h1> heading and a short personal biography.

Created a Portfolio area using semantic elements such as <section>, <figure>, and <figcaption>.

Added a “Skip to content” link to improve accessibility for keyboard navigation.

2. Semantic choices I made (REQUIRED)
Decision 1

Element(s) used: <header> and <footer>

Location on the page: At the beginning and the end of the webpage.

Reason for using these elements: They act as clear structural landmarks, helping screen readers and browsers identify the main introductory content and the concluding or site-wide information.

3. Accessibility considerations

Implemented a Skip Link so users navigating with a keyboard can jump directly to the main content without passing through the header each time.

4. What I learned

I learned how to correctly organize images and their descriptions by using semantic elements like <figure> and <figcaption> instead of relying only on <div> elements.

5. What I still need to improve

I need more practice with advanced table layouts and improving accessibility in web forms.
